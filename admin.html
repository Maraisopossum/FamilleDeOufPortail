🛠️ Admin — Questions du Quiz

Outil pour éditer, ajouter, importer en masse et supprimer des questions/catégories, sans jamais retoucher le JSON à la main. Cette page n'est pas reliée au jeu — garde son URL pour toi.

1. Connexion à Supabase

Renseigné une fois, c'est sauvegardé sur cet appareil. Utilisée pour les questions ET les profils (même projet Supabase que ton jeu).

Migration unique depuis GitHub (si tu utilisais l'ancien questions.json)

Ceci ne sert qu'une seule fois, pour transférer tes questions existantes vers Supabase.

👤 Gestion des profils (Supabase)

Utilise la même connexion Supabase que ci-dessus.

2. Générer des questions avec l'IA

Utilise ta propre clé API. Elle reste uniquement sur cet appareil, jamais envoyée ailleurs qu'au fournisseur choisi.

3. Ajouter des questions manuellement

Ajout en masse depuis un texte ou un fichier

Une question par ligne, 8 champs séparés par | :
Catégorie|Question|Réponse A|Réponse B|Réponse C|Réponse D|IndexBonneRéponse(0-3)|Petit fait
Exemple :
Cinéma|Qui réalise Titanic ?|James Cameron|Steven Spielberg|Ridley Scott|Peter Jackson|0|Sorti en 1997.
